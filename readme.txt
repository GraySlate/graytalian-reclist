Hello!  This folder contains all resources for recording and configuring GrayTalian voicebanks.

GrayTalian is a custom X-Sampa Italian reclist.  All GraySlate Italian UTAUs use GrayTalian.

Resources included:

- GrayTalian Development Guide PDF
- Full GrayTalian reclist
- Full OREMO GrayTalian reclist
- X-Sampa phoneme pronunciation guide
- Full base oto
- Full suffixed base oto
- Sample recording examples
- Sample UST (Giovani Wannabe - Pinguini Tattici Nucleari, UST by GraySlate)

GrayTalian release video:  https://youtu.be/iTXnktAI9Sw

Example bank:  https://www.dropbox.com/scl/fi/wiy798m5k99vb4ff98xsv/Nevio-Vecoli-GrayTalian.zip?rlkey=az2s1ek2ezkzobpqyy29jd88n&dl=0
