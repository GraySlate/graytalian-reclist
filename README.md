# GrayTalian Reclist

**GrayTalian 1.0** - Reclist and resources for GraySlate's Italian UTAU reclist

## What is GrayTalian?

GrayTalian is a method of Italian UTAU voicebank creation.  All recordings and aliases utilize X-Sampa for transcribing phonemes.  This list is meant to give users the essentials needed for coverage of the Italian language while keeping recording and configuration efficient.<br />
<br />
Personal modifications of GrayTalian 1.0 for private use are fully permitted without permission required. Please ask permission before distributing modified GrayTalian reclists. 
## GrayTalian 1.0 Specs Breakdown

- Number of recordings: 201 per pitch
- Number of oto lines: 833 (approximately)

## Reclist Package Contents

- GrayTalian 1.0 Development Guide PDF
- Full GrayTalian 1.0 reclist
- Full OREMO GrayTalian 1.0 reclist
- X-Sampa phoneme pronunciation guide
- Full base oto
- Full suffixed base oto
- Sample recording examples
- Sample UST (Giovani Wannabe - Pinguini Tattici Nucleari, UST by GraySlate)

## Recommended Recording Steps

[OREMO](<https://github.com/SuibianP/OREMO_Unicode/blob/master/OREMO-3.0-b190106-CHS-b190306-Unicode-b200314.zip>) or [Recstar](<https://github.com/sdercolin/recstar/releases>) are recommended for recording GrayTalian voicebanks.  VV and CC strings vary in length but if you want to use Guide BGM, any 2-syllable BGM will work with the main CV section of the reclist.<br />
<br />
Portions of the reclist can be separated into distinct output folders or the reclist can be divided when loading it into OREMO or Recstar for ease of recording.  By default, all recordings for GrayTalian are placed in the same folder per pitch.

## Oto Configuration

[vLabeler](<https://vlabeler.com/>) is recommended for configuring GrayTalian otos. Simply load your voicebank and base oto into the .lbp file over the example voicebank and oto.<br />
<br />
For more in-depth and specific otoing guidance, consult the Development Guide included in the package.

## Voicebank Usage

GrayTalian is developed primarily for Classic UTAU usage or phoneme-only usage in OpenUTAU.  GrayTalian 1.0 has not been tested with any existing Italian OpenUTAU phonemizers or dictionaries.
